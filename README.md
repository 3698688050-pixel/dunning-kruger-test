# 邓宁-克鲁格效应自测

先凭直觉预测自己能答对几题，再答 12 道题，然后把预测和实际摆在一起看落差。

题目属于认知反思测试（CRT）一类的陷阱题：球拍与球、5 台机器、睡莲铺满湖面、硬币连出正面、两家医院的出生比例。答错不是因为难，是因为大脑先给了一个「看起来对」的直觉答案，而人一旦认定自己懂了，就同时失去了判断自己懂不懂的能力 —— 这正是邓宁-克鲁格效应。

**在线使用**：https://3698688050-pixel.github.io/dunning-kruger-test/

## 怎么用

1. 点「开始测评」，先选一个预测答对题数（凭直觉选，别按计算）
2. 答 12 道单选题，每题选完立刻给解析，讲清为什么会掉进坑里
3. 结果页把预测和实际答对题数并排对比，按两者落差给判定

| 落差（预测 − 实际） | 判定 |
|---|---|
| ≥ 4 题 | 严重高估，站在「愚昧之巅」 |
| 2–3 题 | 轻度高估 |
| 0–1 题 | 校准良好，预测和实际吻合 |
| 负数 | 低估自己 |

## 边界

- 12 题样本太小，答对几题和真实认知能力没有稳定关系，不能当测试结果用
- CRT 测的是「愿不愿意停下来验算」，不是智商，也不是专业水平
- 判定文案是玩梗（愚昧之巅 / 绝望之谷），别拿它给人下结论

## 本地运行

双击 `index.html`，不需要服务器，不需要安装任何东西。
